## 摘要
将于2027年发射的南希·格雷斯·罗曼太空望远镜（Roman）有潜力首次直接成像反射光中的系外行星。Roman成像将对系外行星轨道参数引入新的约束，因为反射光强度取决于轨道相位。在本注释中，我们讨论了开源Python软件包orbitize!的一个扩展，该扩展允许用户使用来自天体测量和轨道相位引起的光度变化的联合约束来建模系外行星轨道。为了研究将光度数据加入轨道模型的影响，我们模拟了部分轨道的真实测量，包括在我们的模型中包含和不包含光度测量，并计算了轨道后验概率。我们发现，与仅拟合天体测量相比，同时拟合天体测量和光度测量提高了后验精度。这种效应对于更高信噪比的图像更为明显；例如，当包含光度测量时，信噪比为10的光度数据使倾角精度提高了33%，而信噪比为3的数据仅提高了12%。

## Abstract
Launching in 2027, the Nancy Roman Grace Space Telescope (Roman) has the potential to directly image exoplanets in reflected light for the first time. Roman imaging will introduce new constraints on exoplanet orbital parameters, since reflected-light intensity depends on orbital phase. In this Note, we discuss an addition to the open-source Python package orbitize!, which allows users to model exoplanet orbits using joint constraints from astrometry and photometric variations due to orbital phase. To investigate the impact of adding photometric data into the orbital model, we simulated realistic measurements of partial orbits, both including and excluding photometry in our model, and computed orbital posteriors. We found that fitting both astrometry and photometry improves posterior precision relative to fitting astrometry alone. This effect was more pronounced for higher-SNR images; for example, photometric data with SNR=10 yielded 33% improvement in inclination precision when including photometry, while SNR=3 data yielded only 12% improvement.
